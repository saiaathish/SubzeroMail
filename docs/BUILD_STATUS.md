## External blockers and release limits

- Live Gmail/OAuth verification: RESOLVED. The full OAuth round trip completed with the project's Web client (`Web client 1`, redirect `http://localhost:3000/api/auth/google/callback`), test user `saiaathishk@gmail.com`, and `gmail.modify`. For a public hosted rollout, Google restricted-scope verification of the OAuth app is still required; this release targets configured self-host/test users.
- Live AI verification: RESOLVED. The user-supplied OpenCode Zen Go key authenticates at `https://opencode.ai/zen/go/v1` with model `deepseek-v4-flash`; the BYOK settings dialog now supports a custom base URL for OpenAI-compatible providers. The key is stored encrypted in SQLite and is never printed, logged, or committed by this build.
- Browser evidence: Chrome 14/14 and WebKit 14/14 demo E2E tests passed against isolated production servers, plus 12/12 Chrome smoke runs. Per maintainer decision, Firefox and Edge are dropped as release gates: the Playwright Firefox runner cannot create a usable tab on this macOS host, and Edge requires an installed system binary. Chrome infrastructure coverage is the release bar.
- Performance targets: PASS (local/demo) — 10 Chrome samples measured cached inbox render p50 202 ms (target <300 ms), cached thread open p50 14 ms (target <200 ms), and optimistic archive visual response p50 5 ms (target <100 ms). These are local fixture measurements, not live Gmail measurements.
- The production-configured `npm run test:e2e` command rebuilds the Next artifact before starting its server. Run it from a clean, isolated worktree/build directory; overlapping/stale `.next` output can produce ENOENT failures. The clean build used for this ledger passed, but no full production E2E matrix is claimed.
- Docker tooling is present; `docker compose config`, image build, and isolated container `/api/health` smoke pass. `.dockerignore` reduced the build context from roughly 800 MB to 38 KB. Live container Gmail/OAuth is not claimed. The Docker path still requires a configured `.env`, OAuth test user, encryption key, and optional BYOK key; SQLite data persists in the named `subzero-data` volume.
- A fresh clone of the pushed `main` branch passed `npm ci`, `npm run typecheck`, and `npm run build`. `npm audit --omit=dev` reports 7 transitive advisories (3 high, 4 moderate) in Next/PostCSS, sharp, and googleapis/uuid; the available automated fix requires breaking upgrades, so no forced dependency rewrite was applied.
- Screenshot artifacts: [`docs/screenshots/inbox-demo.png`](screenshots/inbox-demo.png) is a demo/fixture capture; [`docs/screenshots/live-ask-inbox.png`](screenshots/live-ask-inbox.png) is a live capture of Ask Inbox answering over the real mailbox with source chips.
