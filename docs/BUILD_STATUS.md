## External blockers and release limits

- Live Gmail/OAuth verification is `BLOCKED` because the configured Google ID/secret are placeholders, then browser authorization with an authorized test mailbox is still required. The callback is configured for port 3000, currently occupied by another local app. Public unrestricted Gmail restricted-scope verification may also be required for a hosted rollout; the first OSS release can target configured self-host/test users.
- Live AI verification is `BLOCKED` until a supported Subzero BYOK provider key with available quota is supplied and configured. No supported provider key is present in `.env.local`; no key is requested, printed, or committed by this build.
- Browser evidence: Chrome 14/14 and WebKit 14/14 demo E2E tests passed against isolated production servers, and 12 consecutive Chrome smoke runs passed (12 smoke tests per run). Firefox was attempted but its bundled browser could not create a usable tab in this macOS runner (`MachCheckInListener TimedOut`); Edge runs only with `SUBZERO_INCLUDE_EDGE=true` and an installed `msedge`, which is unavailable here.
- Performance targets: PASS (local/demo) — 10 Chrome samples measured cached inbox render p50 202 ms (target <300 ms), cached thread open p50 14 ms (target <200 ms), and optimistic archive visual response p50 5 ms (target <100 ms). These are local fixture measurements, not live Gmail measurements.
- The production-configured `npm run test:e2e` command rebuilds the Next artifact before starting its server. Run it from a clean, isolated worktree/build directory; overlapping/stale `.next` output can produce ENOENT failures. The clean build used for this ledger passed, but no full production E2E matrix is claimed.
- Docker tooling is present; `docker compose config`, image build, and isolated container `/api/health` smoke pass. `.dockerignore` reduced the build context from roughly 800 MB to 38 KB. Live container Gmail/OAuth is not claimed. The Docker path still requires a configured `.env`, OAuth test user, encryption key, and optional BYOK key; SQLite data persists in the named `subzero-data` volume.
- A fresh clone of the pushed `main` branch passed `npm ci`, `npm run typecheck`, and `npm run build`. `npm audit --omit=dev` reports 7 transitive advisories (3 high, 4 moderate) in Next/PostCSS, sharp, and googleapis/uuid; the available automated fix requires breaking upgrades, so no forced dependency rewrite was applied.
- Screenshot artifact: PASS (local/demo) — [`docs/screenshots/inbox-demo.png`](screenshots/inbox-demo.png) was captured from the production build in Chrome at 1440×900 and visually inspected. It represents fixture/demo data, not live Gmail behavior.
